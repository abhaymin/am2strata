This PC

          
Start at boot
            
PolyStrata's service (strata-orca) starts at boot today. To make am2Strata the boot service with the
              same configs and models, run in the am2strata folder:

            
cargo run -q --release --bin am2strata-run -- install --port 8000

            
am2strata-run uninstall gives the boot service back to PolyStrata.

Continue chats past the context

            newest message come back. Works with every model, at any context size.

Tools (MCP)

          

            
Tool servers

            

            
Their tools run on this PC with your rights, when the model decides to call them (in this
              page's chat only; switch it off in the chat's sampling settings).

          

          

            No tool servers yet
            
Add an MCP server - a program on this PC or an address - to the default model's run config and the chat
              can use its tools:

            
"mcp_servers": {
  "files": {"command": "npx", "args": ["-y", "@modelcontextprotocol/server-filesystem", "/home/you/Documents"]},
  "search": {"url": "http://127.0.0.1:9000/mcp"}
}

            
Then restart am2Strata. Tools run with your rights on this PC, so only this page can use them.
