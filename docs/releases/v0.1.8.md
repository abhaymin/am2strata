**am2Strata v0.1.8**: a Workshop for making models and training data, a sandbox VM for computer use, HTTPS, API keys
with usage, one live WebSocket channel, installers for six platforms, and a regression suite.

## Install or update

**Linux (x86_64, arm64) and macOS (Apple silicon, Intel):**

```bash
curl -fsSL https://github.com/abhaymin/am2strata/releases/latest/download/install.sh | sh
```

**Windows (x64, Arm64), in PowerShell:**

```powershell
irm https://github.com/abhaymin/am2strata/releases/latest/download/install.ps1 | iex
```

Running it again over an earlier version keeps your models and settings. `am2strata-run doctor` then lists each
optional feature and what this machine still needs for it.

On Linux arm64, Intel Macs and Windows Arm64 the Rust engine runs on the CPU only. The Computer tab's desktop and the
sandbox VM are Linux-only; the VM also needs an x86_64 PC with KVM.

## New

### Workshop (a new tab, and `am2strata-run workshop`)
- **Convert** a Hugging Face Llama-family model to GGUF, byte for byte as llama.cpp's converter writes it; **quantize**
  it (Q8_0, Q6_K, Q5_K, Q4_K, Q4_0, as `llama-quantize --pure`); **merge** a LoRA adapter from Unsloth or PEFT into its
  base; **install** the result so it appears in the model list. All in Rust, no Python.
- **Training data** written by the model you have loaded: questions and answers or multi-turn chats from your
  documents (text, Markdown, code, HTML, PDF), or more examples like your own. Near-duplicates are dropped, an optional
  judge pass scores each answer against its source, and every dataset gets a card. Review, edit and delete records in
  the tab.
- Jobs run one at a time in a separate process, and only inside the Workshop's folders.

### Sandbox VM for computer use (Linux)
- A Debian 13 virtual machine am2Strata creates and runs itself (QEMU with KVM; no root, no Docker). The agent is root
  inside it and can install or remove anything; this PC is untouched. Turn it on with
  **Settings › Computer and browser use › Mode: Sandbox VM**, or use it yourself from the **Computer** tab.
- **Light:** it only gets CPU time that nothing else is using, has a memory ceiling, no GPU, pauses when unused, and is then
  saved to disk; a start restores it with its open apps in about a second.
- **Apps:** Chromium, Firefox ESR, Bitwarden, Tailscale, NetBird, Mullvad, Surfshark, WireGuard and OpenVPN, VS Code,
  LibreOffice and more with one click; anything else by Debian package, Flathub id, `.deb` or AppImage link.
- **Ads:** a DNS filter with Pi-hole's default list, the AdGuard DNS filter or both, a let-through list for jobs that
  must see a site as it is, and an "Ads and trackers" app on the VM's desktop.
- `am2strata-run vm status|start|stop|install|exec|ads|settings`.

### The Computer tab
- See the desktop computer use works on, live; **Take control** to use it with your own mouse and keyboard while
  the agent waits; copy and paste between your clipboard and its clipboard.

### HTTPS and secure WebSockets
- **Settings › Secure connection** (and `am2strata-run tls`): a self-signed certificate made for you, your own
  certificate, or a Tailscale certificate browsers trust. HTTPS and `wss://` are on port 8001 by default.
- Plain `http://` and `ws://` keep working beside it. You can instead send other devices, or everyone, to HTTPS; HSTS
  is sent only when everyone is.

### API keys and usage
- Make keys while the server runs (**Settings › Clients**, `am2strata-run keys`): a name, tool sets, an expiry, daily
  request and token limits, allowed models. A key is shown once and stored only as a hash.
- A generated key opens the model APIs and never the server's settings.
- **Usage** per key and per model, per day: requests, tokens, media jobs, errors.

### One live channel
- `GET /v1/live` over `ws://` or `wss://`: the server pushes status, the queue, jobs and Monitor figures when they
  change, and any API request can be sent over the same socket with streamed answers and cancel. The Monitor tab uses
  it and falls back to polling. `am2strata-run live` prints the pushes for scripts.

### Installers and platforms
- Downloads for Linux arm64, Intel Macs and Windows Arm64 join the existing three. The installers detect the OS and
  CPU, check the download's SHA-256, install without sudo, and can uninstall.

### Regression suite
- A contract table of every route (who may call it, and what each kind of caller gets), recorded response shapes for
  the compatible APIs, and one test per bug class fixed before. `am2strata-run regression` checks a running server
  after an update and prints a pass/fail table.

## Fixed
- A chat request whose JSON body was not an object caused a server error; it is now a 400.
- Seven owner routes that change state did not refuse requests from another site's page.
- A request with a broken body is now refused for its missing key before its body is looked at.
- Training-data chunks could exceed their size limit when they held blank lines or indentation.
- Tests no longer race on shared fixtures or on the process environment.

## Notes
- Sign-ins inside the sandbox VM (a password manager, a VPN, a browser account) are yours: open the app in the
  Computer tab, take control and sign in.
- Training models (LoRA) in the Workshop is not in this release; train with Unsloth on a dataset made here and merge
  the adapter in the Workshop.
- The installer downloads a headless Chrome for the browser tool without a checksum; `--no-browser` skips it.
