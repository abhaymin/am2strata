**am2Strata v0.1.1**: coding agents in one command, the Gemini API, a Monitor that keeps its history, and Chatterbox
speech in the media engine.

## Install

**Linux (x86_64) and macOS (Apple Silicon):**

```bash
curl -fsSL https://github.com/abhaymin/am2strata/releases/latest/download/install.sh | sh
```

**Windows (x64), in PowerShell:**

```powershell
irm https://github.com/abhaymin/am2strata/releases/latest/download/install.ps1 | iex
```

Already on v0.1.0? Run the same command again: it replaces the program and keeps your models and settings.

## New

- **Coding agents in one command:** `am2strata agentrun <agent>` starts an agent on your models, on this PC or on
  another one (`--url http://<host>:8000 --api-key …`). Everything after the agent's name goes to the agent.
  - Started for you: Claude Code, Codex, opencode, Pi, Qwen Code, Aider, Goose and the Gemini CLI.
  - `am2strata agent setup <agent>` writes an agent's own config once (it keeps a backup, and `agent reset` puts it
    back): Claude Code, Codex, opencode, Pi and Factory Droid.
  - Oh My Pi, Crush, Hermes, OpenClaw, Continue, Cline, Kilo Code, Zed and VS Code get the exact settings to enter,
    in Settings › Connect › Coding agents and with `am2strata agent show <agent>`.
  - `unsloth start` reaches am2Strata too (`UNSLOTH_STUDIO_URL` and `UNSLOTH_API_KEY`).
  - Not supported: the Antigravity CLI and the Cursor CLI, which take no custom model endpoint.
  - See [docs/AGENTS.md](https://github.com/abhaymin/am2strata/blob/main/docs/AGENTS.md).
- **The Gemini API:** `/v1beta/models/<model>:generateContent`, `:streamGenerateContent` and `:countTokens`, with
  the key as `x-goog-api-key` or `?key=`. Gemini clients and the Gemini CLI work by changing the base URL.
- **Monitor:**
  - the request history is kept on disk until you clear it;
  - each request shows the model it ran on;
  - media jobs keep their output: images, video and audio play in the table;
  - a running job is named by its kind ("Speaking · part 2 of 3", "Making an image").

## New in the build from source (the media engine)

- **Chatterbox text to speech** (Resemble AI, MIT), through ONNX Runtime with the `onnx` feature:
  - Chatterbox Turbo (English, with tags such as `[laugh]`) and Chatterbox Multilingual (20 languages here, Hindi,
    Spanish and French among them);
  - the voice of a 5 to 10 second clip (`voice_audio` in `/v1/audio/speech`), or a built-in voice;
  - it runs on the CPU, beside the text model, so chats do not wait. Measured on a Ryzen 7 7840HS (8 threads):
    9.2 s of speech in 10.7 s, 5 GB of RAM at its peak;
  - it needs ONNX Runtime 1.23 (`sudo apt install libonnxruntime1.23`, or `ORT_DYLIB_PATH`);
  - clone only a voice whose speaker has agreed to it.

## Fixed

- A server whose default model's run config has no `api_key` now uses the key of the newest other run config, and
  says which. Before, changing the default model to one without a key left a server on `--host 0.0.0.0` open to the
  network.
- A media job whose client went away no longer shows as running for ever in the Monitor.
- The README's "Not yet" claims only what was measured.

## What to expect

As in v0.1.0:
- the download's engine runs on the CPU, and suits small models;
- the fast NVIDIA path, and image, video and speech generation, need the build from source
  ([docs/DEPLOYMENT.md](https://github.com/abhaymin/am2strata/blob/main/docs/DEPLOYMENT.md));
- by default the server answers only this PC: set an API key before `--host 0.0.0.0`.

Each model has its own licence, which is yours to read. am2Strata itself is MIT.
