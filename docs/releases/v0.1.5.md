**am2Strata v0.1.5**: clusters of PCs, a model optimizer, a video maker for the chat, long videos as chains of clips,
songs that continue, a new voice, and a browser that can upload a file and asks before it publishes.

## Install or update

**Linux (x86_64) and macOS (Apple Silicon):**

```bash
curl -fsSL https://github.com/abhaymin/am2strata/releases/latest/download/install.sh | sh
```

**Windows (x64), in PowerShell:**

```powershell
irm https://github.com/abhaymin/am2strata/releases/latest/download/install.ps1 | iex
```

Running it again over an earlier version keeps your models and settings.

## New

### Clusters
- **A master and its workers:** a master routes chats to the workers that have the model (Settings › Cluster shows
  each worker, whether it answers, its models and its queue).
- **Joining is simple and private:** a worker joins with a pairing code and is found on the network by mDNS; master
  and workers talk over mutual TLS 1.3 with the paired certificates pinned.

### The model optimizer
- **Tuned for this PC:** it reads the machine (GPUs, the GPU link at its real width, the disk), searches the engines'
  own speed flags within bounds, and keeps a tuned profile that is used at load. Settings › Models: tune a model,
  follow the run, and switch its tuned settings on or off.
- **A quality floor:** a tuned setting is kept only if the model still agrees with its default run.
- **Quantization advice:** each quant marked by how it fits this PC, with the recommended and the fastest.

### Long videos and media
- **A video maker the chat can use:** `compose_video` (and `POST /v1/media/videos/compose`) joins pictures, clips,
  audio, captions and a title and end card into one MP4, landscape or vertical for Shorts; `make_thumbnail` (and
  `POST /v1/media/thumbnails`) puts big words on a picture for a 1280x720 thumbnail.
- **Long video as a chain of clips:** Wan's one-frame carry between clips, the colour held to the first clip,
  crossfaded joins, the carried frame redrawn by the image model (on by default, measured), and each step shown in
  Monitor.
- **Big Qwen Image pictures** decode on the CPU, and a video can start from an image.
- **Media jobs survive a restart**, ids never repeat, and "Make it again" re-runs one; media jobs wait for memory.
- **Productions ready for YouTube:** one request, many parts, one audio file, with chapters in the description's
  form and captions from the finished audio.

### Songs and voices
- **Songs continue:** a song continued from the one before (repainted past its end), starting from the last sound and
  singing its lyrics; in the engine, the music API and productions. ACE-Step's audio encoder now runs in Rust
  (110 dB SNR against the reference).
- **The planner writes a missing tempo, key and time signature first.**
- **Gautham**, a new named voice: a warm Indian-English male. Indic Parler speaks each language with its own speaker;
  Parler's pauses stay under 0.2 s and a held last sound is trimmed.

### The browser (computer use)
- **`browser_upload`:** attaches a file to a page's upload field, only from an upload folder the operator names
  (`"browser": {"upload_dir": ...}`); nothing outside it, no `..` or links pointing out.
- **Publishing asks first:** clicks on Publish, Save, Upload, Delete, Share, "Make public" and the like wait for your
  yes, as passwords and form submits already did. With `"browser": {"approve": "job"}` one yes covers that job on
  that site for 30 minutes; any other risky step still asks each time.
- **Steadier:** a hung page no longer takes the tool down; typing replaces a field's text; the same step three times
  on an unchanged page is stopped.

### Clients and APIs
- **Client profiles:** their tools, memory and limits (image size, video length, web searches per answer), in
  Settings › Clients; `run_python`, the browser and `/v1/memory` for profiles; media jobs per hour.
- **Responses API hosted tools:** `image_generation` and `mcp`. Gemini's `google_search` is answered by the server's
  web search.
- **Downloads show their progress:** percent, done and left, speed and time left.
