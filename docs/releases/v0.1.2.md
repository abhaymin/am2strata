**am2Strata v0.1.2**: fixes to the web app's Monitor and media pages.

## Install or update

**Linux (x86_64) and macOS (Apple Silicon):**

```bash
curl -fsSL https://github.com/abhaymin/am2strata/releases/latest/download/install.sh | sh
```

**Windows (x64), in PowerShell:**

```powershell
irm https://github.com/abhaymin/am2strata/releases/latest/download/install.ps1 | iex
```

Running it again over an earlier version keeps your models and settings.

## Fixed

- **Monitor:** with a long history, or media players in its rows, the requests table spread under the cards below it.
  It now scrolls inside its card, and the row is taller.
- **Media models:** while an image or a video was being made, Settings › Media models waited behind the job and said
  "the media engine is not built". It now shows the last list at once, says that a job is running, and says
  "Loading" until the server answers.

## New

- The web app shows the server's version beside its name (`/metrics` carries it as `"version"`).
- **Monitor:** a System RAM card shows the RAM used of the total, the share used, what is free, and its history.
