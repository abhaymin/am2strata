**am2Strata v0.1.10**: the Rust engine runs mixture-of-experts models bigger than the RAM, borrows memory from
another machine for them, and is several times faster on the CPU and the GPU, with a native Metal backend for Apple
silicon. Also browser use for every client, specialist models in a turn, agent evals, VM snapshots, and the media
and cluster commands in the CLI.

## Install or update

**Linux (x86_64, arm64) and macOS (Apple silicon, Intel):**

```bash
curl -fsSL https://github.com/abhaymin/am2strata/releases/latest/download/install.sh | sh
```

**Windows (x64, Arm64), in PowerShell:**

```powershell
irm https://github.com/abhaymin/am2strata/releases/latest/download/install.ps1 | iex
```

Running it again over an earlier version keeps your models and settings.

## New

### The Rust engine (am2strata-hybrid)
- **Models bigger than the RAM:** the hot experts are kept in memory (locked, or copied into the engine's own memory
  where the lock limit refuses), the cold ones are read from the disk, and a learned profile (`--expert-profile`)
  keeps the experts a model really uses. The matrices every token uses are kept in memory too.
- **Memory across machines:** a paired machine lends its RAM as the next tier for experts
  (`--serve-experts` on the lender, `--remote-experts` on the machine running the model), over mutual TLS with the
  cluster's pins. The tiers go GPU memory, RAM, another machine, then the disk. Tokens are identical with and without
  it, on any pairing (Linux with macOS, either way). A 16 GB Mac mini running Cyber-Tiel (38 GB) with 27 GiB of a PC's
  RAM: prompt 6.05 -> 24.10 tok/s, generation 4.61 -> 9.61 tok/s.
- **Faster on the CPU, the same tokens:**
  - integer kernels for Q4_K, Q5_K, Q6_K and Q8_0, hand-written for AVX2 and for NEON (`sdot`), bit-identical to the
    plain ones;
  - prompts read in chunks of 32 for every architecture (mixture of experts, MLA, gated delta nets, hyper-connections),
    each weight row unpacked once per chunk, IQ types included;
  - a MoE layer's chosen experts, and MLA's heads, computed in one parallel pass.
- **Prompt-lookup drafting** (`lookup=k` per request, or `AM2_LOOKUP`): guesses from the context, checked in one pass,
  with exactly the tokens the model gives without it. Code edits, CPU: Cyber-Tiel 8.69 -> 13.61 tok/s, Ministral 3B
  14.2 -> 21.1.
- **The same results on every machine:** the engine's maths (exp, log, sin, cos, pow) no longer depends on the
  platform's math library, so Linux and macOS give the same logits to the last digit.

### GPUs
- **A native Metal backend for Apple silicon** (`metal:*` with `AM2_METAL_NATIVE=1`): one command buffer per token,
  SIMD-group products and matrix-unit prompt products. Ministral 3B on a Mac mini M4: generation 12.3 -> 36.8 tok/s,
  prompt 12.4 -> 367 tok/s. The CubeCL path stays the default until it has run longer.
- **Faster Q4_K and Q6_K products on every GPU** (CUDA, HIP, Vulkan): contiguous reads across a warp and x in shared
  memory. Ministral 3B on an RTX 5060 Ti with `--graph`: 49.8 -> 90 tok/s.
- `--graph` (a whole token on the device) is on by default; Metal's 32 KiB shared-memory limit no longer gives wrong
  tokens.

### Browser use (a new Browser tab, `am2strata-run browser`, and MCP)
- **One browser engine, three browsers:**
  - the server's own headless Chrome (no logins, public sites only);
  - your Chrome, through its DevTools port, with your logins;
  - Chromium on the sandbox VM's desktop, which you watch and take over on the Computer tab.

  Pick one per request with `"strata_browser": "server" | "mine" | "sandbox"`.
- **New tools:**
  - **Pages:** numbered page elements to click and type into; `browser_screenshot` of the whole page or one element;
    `browser_forward`; `browser_script` (off unless allowed, and it asks every time).
  - **Forms and surveys:** filled by label, never sent without a click.
  - **Scraping:** tables (merged headers read correctly; the biggest table by default), repeated items, links and page
    metadata across up to 50 pages, saved into keyed datasets that export as CSV or JSON.
  - **Maps:** drag, wheel and keys.
  - **Site checks:** status, console errors, failed requests, load time, broken links.
- **Site tests** run without a model, from the Browser tab, the CLI or the API, with JUnit output for CI.
- **Your own steps:** a Browser tab with a live page you click, scroll and type on, plus datasets, tests, and steps
  waiting for your yes.
- **For coding agents:** an MCP server at `/v1/mcp/browser`. Add it to Claude Code and other agents with your key.
  Risky steps (passwords, sending forms, publishing) wait for your yes on the Browser tab.
- Docs: [BROWSER-USE.md](../BROWSER-USE.md).

### Media library and image editing
- **A media library:** every image, video and sound made here, and every one sent to edit or transcribe, is kept
  once and can be used again by its id (`mf_…`) in any media request. Files go after 90 days unless pinned
  (`media_files_max_age_days`), within 10 GB (`media_files_max_gib`). It has a Library view on the Media tab,
  `/v1/media/files`, and `am2strata-run media files | add | get | rm | pin | unpin`.
- **How much an edit keeps of the original:**
  - `strength` (on models that redraw from an image, such as Z-Image);
  - a `mask` of what may change, with the original's own pixels kept outside it on every model;
  - `keep_colors` and `blend`;
  - in the app: a mask painter, and each edit shown over its original with a slider.

### Models helping models
- **`ask_expert`:** the model can send one sub-question to a specialist model in the same turn, including a small model
  on a paired cluster worker.

### Agents and safety
- **Agent evals:** `am2strata-run eval run | selftest | lock | list`, with jobs whose checkers are written and locked
  before any model runs.
- **Sandbox VM snapshots:** taken before every job in the VM, with rollback.
- **Protected things:** `computer.protect` in the run config lists containers, services and paths the VM shell will not
  touch destructively.
- **Web search that does not break:** several backends in turn; one that fails is skipped for 10 minutes.
- **Throwaway browser sessions:** each browser-use session runs in its own private browser context. Its cookies,
  cache and storage are deleted when it ends or after 10 minutes idle, and with no session left the server's browser
  closes and its profile folder is removed. Your own Chrome (`connect`) keeps its profile.

### Command line
- `am2strata-run media` for image, video, speak, song, transcribe, check, dub, produce and job.
- `am2strata-run cluster`, `tune`, `clients` (including `clients edit`) and `memory`.

### Media and Workshop
- **Video without ffmpeg:** MP4/H.264 frames come from the media engine; MP4s with B-frames give their keyframes or a
  clear refusal.
- **Web tools:** media check, dubbing and productions cards on the Media tab.
- **Workshop convert** writes `general.basename`, `general.finetune` and `general.version` from the model id, as
  llama.cpp's converter does.

### Monitor and cluster
- **Every machine of a cluster** in Settings › Server and access: each worker's GPUs, CPU, memory and NPUs, with
  their load, including Apple silicon's GPU and Neural Engine (`GET /api/cluster/system`).
- **Media jobs in Monitor:** the step, the seconds per step and the seed while an image, video or song is made.

### Settings
- **Settings › Clients:** edit a generated key's name, tools, limits, expiry and models; its expiry stays unless you
  pick another.

## Fixed
- **macOS and Windows:**
  - free RAM read 0 on macOS and Windows;
  - install hints, the Tailscale lookup, LAN certificate names and the HTTP redirect were Linux-only;
  - ffmpeg, ffprobe and tailscale were not found when the server runs under launchd;
  - the Mac GPU path hung without an error.
- **A cluster worker's own HTTPS** cut off its master.
- **Engine:**
  - the machine running a model gave up while the lender was still loading its share;
  - an expert counts as on a GPU only when all its matrices are;
  - Orca and other hyper-connection models gave different tokens on Linux and macOS.
- **A stalled engine** ends a chat with an error instead of waiting forever.
- **A publishing or form-sending click was never asked about,** and `browser_select` always failed. The browser's click
  lookup answered JSON that was never parsed.
- **A tab whose DevTools session died, or a browser that went away,** made every later step fail until a restart. The
  browser now reconnects by itself.
- **The browser's error log carried over from earlier pages,** so a site check could fail because of another page.
- **Dubbing** (`/v1/media/dub`, `dub_narration`):
  - it returned a silent soundtrack;
  - a 24 kHz take played at double speed;
  - the report named the wrong lines;
  - without ffmpeg, a take that was too long was cut instead of sped up. Speed-up is now a time-stretch in Rust that
    keeps the pitch.
- **`check_media`** transcribes a take in its own language with the most accurate Whisper on the server. A word-perfect
  German take used to score 0.43.
- **The Workshop's Train card** said training was "coming next"; it now explains how to train from the command line.
- **The release tests pass on all six platforms**: Windows paths keep their own separator, the Tailscale check finds
  `tailscale.exe`, the live browser tests use the runner's Chrome, and a missing VM memory sample no longer fails (#96).
- v0.1.9 was tagged but never released; this is the release it was meant to be.

## Notes
- The native Metal backend is opt-in (`AM2_METAL_NATIVE=1`) in this release.
- Prompt-lookup drafting is off by default and runs on the CPU path only.
- Lending memory to another machine is started from the command line; Settings › Cluster does not set it up yet.
